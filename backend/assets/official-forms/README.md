The current header uses 76 pt and 72 pt image boxes respectively, preserving aspect ratio. Effective resolutions are approximately 134 and 207 dpi. Fine seal lettering will remain softer than the surrounding vector text; higher-resolution official replacements would improve print quality. No upscaling, tracing, recoloring, or photographic logo crop was substituted.

The renderer receives image bytes explicitly. File loading belongs to the sample script and, later, the approved integration layer. Deployment packaging of these files is a later integration concern.
