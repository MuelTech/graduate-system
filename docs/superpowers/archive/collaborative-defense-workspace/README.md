# Collaborative Defense Workspace Archive

This directory contains historical implementation, verification, acceptance,
and design evidence produced during the Collaborative Defense Workspace (CDW)
initiative.

The initiative is complete and merged into `main`. These files are retained for
traceability and audit history; they are **not** the primary source for current
system behavior.
